# Automatic Timeline Generation and Anomaly Flagging for Surveillance Video

A CNN-LSTM multi-task autoencoder that watches a surveillance video stream and produces two outputs: an anomaly score per clip (reconstruction error) and a labelled event timeline (Normal / Fighting / Robbery / Arson / Burglary).

Run notebooks `01` → `05` in order after placing the UCF-Crime dataset in `data/ucf_crime/`.
